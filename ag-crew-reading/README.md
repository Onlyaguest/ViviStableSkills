# AG CREW Reading

把文章变成可回源的多视角围读，再按需进入“学会模式”。保留完整 Markdown；Roam、Pilot、Cohub 均使用接收者自己的配置和权限。

入口：[接入和调用说明](references/onboarding.md)。Agent 从 [SKILL.md](SKILL.md) 开始。

首次使用可填写职位、当前主要工作和关注问题，并选择“保存到本机 / 仅本次 / 跳过”。保存后以后只发链接，正文会稳定包含“对你当前工作的意义”。可随时说“更新我的围读背景”或“删除我的围读背景”。个人配置不随 Skill 分享。

示例：`用 $ag-crew-reading 围读这篇链接，给完整 Markdown，然后带我学会。未确认前不写入外部系统。`

本包不包含原作者账号、私人路由、历史材料或任何授权。通用视角不是 AG CREW 原始角色提示词的复刻。结构校验通过不等于远端服务或真实学习效果已验证。
