# 给同事和 Agent 的接入说明

## 安装与一句话调用

将包中的 `ag-crew-reading` 文件夹放入 Codex 的 `$CODEX_HOME/skills/`，未设置该变量时通常为 `~/.codex/skills/`。已有同名版本先备份、比较，不直接覆盖私人配置。重新打开会话确认可发现；其他 Agent 可直接读取 `SKILL.md` 并按需读取相对路径中的 references。

可以直接发给 Agent：

> 使用 $ag-crew-reading 围读这个链接：<文章URL>。先确认你的可用执行路线，沿用我已有的角色协议；没有时说明备选方案。保留首轮观点、具体碰撞、来源限制和完整 Markdown。不要默认写入 Roam 或公开发布。报告后进入学会模式，一次问一个问题，用我的复述与新案例检验理解。

只要围读时删去最后一句。已有报告可说：“用 $ag-crew-reading 的学会模式带我学这份报告，不要重新派工。”

## 能力与配置

本包是执行协议，不附带模型服务、Pilot 账号、远端 crew、Cohub 空间或 Roam 权限。安装 Skill 不会自动创建这些资源。

- Pilot：使用自己的 CLI、登录、机器身份和已授权 crew 目标。先看本机 `pilot --help`、`pilot crew summon ask --help`、`pilot crew capture --help`、`pilot inbox --help`；以当前版本为准。不要自动升级或复制他人机器名。
- Cohub：使用目标环境已配置的工具或 Cohub Skill，确认空间、会话、角色协议及真实隔离能力。不要求原作者的 wrapper 或绝对路径。
- 本地多 Agent：仅使用当前环境支持且任务授权的委派工具。独立首轮、共享碰撞、收回证据；缺委派工具时不得冒称并行独立执行。
- 单模型模拟：用户接受后可用，显著标记执行方式；功能可用不等于同等独立性。
- Roam：完全可选。使用目标环境自己的授权写入工具，先明确 graph 和父页面/块，查重、写入、回读。没有写层就交 roam.md，不要求安装原作者的私人 Skill。

配置只需明确：执行路线、目标、角色协议位置、输出目录，以及可选写回位置。凭据交给工具自己的认证系统，不能写进 Skill、报告、分发包或提示词。

Pilot 调用示意，替换目标并确认本机参数后使用：

```sh
pilot crew summon ask <your-crew-target> --live -- '<task_id、单篇URL、问题、角色协议和产物要求>'
pilot crew capture <your-crew-target>
pilot inbox --pull
```

保留 task_id；超时先检查已有任务，不自动重发。派工给远端会传输链接及背景，内部材料只能交给有权访问的目标。

## 验收和边界

第一次用公开或用户提供的短材料试读，检查能否打开 Markdown、找到原文证据、区分角色执行模式。随后再测试可选学会模式和写回；不要把所有集成一次接上后仅凭“成功”提示验收。

分享包不含私人 `references/local-routing.md`，也不携带原用户的历史案例与授权。历史成长可导入获准分享的脱敏报告和反思，但不自动同步私人历史。主页发布、长期记忆修改及定时运行均需单独要求。
