Phase 2 Skill Production Line

autoresearch

把“自动迭代优化 skill”的方法论先稳定成一个研究循环脚手架。它现在做的是：初始化工作区、固定 checklist、记录 baseline、打分、写 changelog，为以后更自动化的版本留证据链。

Input: skill + checklist Output: research workspace Commands: init / score / log-iteration Best fit: skill QA loop
Checklist Size
3-6
用 yes/no 问题，不要模糊打分。
Loop Rule
One Change
每轮只改一个点，才知道到底是什么起作用。
Core Artifact
CHANGELOG
最值钱的是保留下来的“什么有效、什么无效”。
Current Scope
Scaffold
先做稳定研究循环，不假装已经有全自动 agent 引擎。

How To Use

先建 workspace，再打分，再记录变更。这样后续 agent 才能接着干。

初始化工作区

python3 main.py init --root /tmp/autoresearch-demo --skill-name "landing-page-skill" --author Developer_Lead --questions "标题是否具体?|是否没有 buzzwords?|CTA 是否具体?"

打分与记录

python3 main.py score --skill-name "landing-page-skill" --answers y,n,y
python3 main.py log-iteration --root /tmp/autoresearch-demo --iteration iter-01 --change "Add explicit headline rule" --before 56 --after 72 --keep

Review Checklist

审核员最少看这 3 条就够。

定位

  • 是否清楚说明这是 research loop scaffold，而不是全自动 optimizer
  • 是否把 checklist / baseline / changelog 三件事讲清楚

执行

  • score 是否能输出结构化分数
  • init 是否能建 workspace
  • log-iteration 是否能把 keep/revert 结果写入 changelog
