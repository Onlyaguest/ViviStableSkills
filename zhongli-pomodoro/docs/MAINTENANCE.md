# 工程维护

## 边界

这是 Mac 原生桌宠。硬件固件在另一个工程，不随本目录部署。代码、构建脚本和测试可进 Git；个人任务编号、日志、番茄记录、偏好设置和构建产物不进 Git。用户视频、角色帧图及音频保留在本地，未经明确授权不公开发布。

## 每次变更

1. 先明确影响计时、模式、资源或状态来源中的哪一块。
2. 修改状态模型时补相应边界测试；运行工具目录的测试脚本。
3. 使用本地素材构建，手工验收右键切换、透明背景、暂停恢复和音效。
4. 更新 README、路线图和变更日志；记录未验证的行为。
5. 更新运行中的应用前保存状态。不能为部署结束用户一轮专注。

## 当前数据

偏好域 online.yuanzi.zhongli-companion：timer 保存当前阶段、剩余时间、累计完成轮数；mode 保存模式。尚无逐轮历史数据库。修改格式前先备份并设计迁移；不重置用户累计。

## Codex 来源

只读本机既有状态文件，每两秒检查指定任务；不读任务正文、不上传状态，不改其他应用的钩子。来源超过十分钟无更新则显示不可用。完成只表示一次回复结束。

## 发布与回退

保留上一个可运行 .app，再构建新版。出现故障先退出新版，恢复旧包；如果数据结构有升级，应按迁移策略恢复，不能盲目覆盖新数据。没有自动发布、定时巡检或开机自启；“持续维护”通过版本管理、测试和变更记录实现。

## 云端测试

本地已通过测试与完整构建。docs/github-actions-template.yml 是待启用的工作流模板；当前 GitHub 凭证缺少 workflow 权限，未安装到 .github/workflows，因此云端测试尚未启用。未来获得相应授权后再安装模板。
