# 桌宠迭代优先级

更新：2026-09-16。以下是待办排序，不代表已实现。

## P0：保存可靠的历史

先记录，再做查看页。每轮专注完成时写入唯一编号、开始/结束时间、有效专注时长和完成状态；暂停不重复记，主动结束不算完成，重新打开不重复计数。保存失败应明确提示，不能静默丢记录。

已有累计轮数保留为“历史累计”，不虚构过去每轮的日期。新记录从升级时起累计。先提供菜单“专注记录”：今日完成、累计完成、按日列表。数据只在本机，支持导出备份；不加登录、云同步或硬件同步。

验收：跨重启不丢失；暂停继续、切换模式、睡眠唤醒、到点退出不会重复计数；升级前累计保持不变。

## P1：小型成就墙

依赖真实历史。先做三枚：第一轮、累计十轮、累计五十轮。清楚显示名称、条件、进度和获得日期；旧累计可以计入轮数，但不能伪造获得日期。菜单打开查看，不常驻、不弹窗、不设连续签到惩罚。

## P2：换皮肤

用户有第二套完整素材时再做。固定阅读、等待、完成、需要处理四类动作，每套皮肤共用计时和历史。缺动作时回退等待；导入时检查尺寸、帧数和总大小。保持低帧率、少量缓存，不同时解码多套皮肤。

先做本地皮肤目录与选择菜单，不做皮肤商店、下载社区或复杂编辑器。与 ChatGPT 内置宠物是否兼容尚未验证，不能承诺直接导入。

## 持续约束

番茄钟和 Codex 陪伴是独立模式。切换不改变计时；后台计时到点可提醒，但不覆盖 Codex 动作。Codex 状态不可用不能假装完成。保持角色为主、菜单承载信息。
