# 钟离版番茄钟 · Mac 桌面版

独立的原生 macOS 桌宠：透明背景、拖动定位、右键番茄钟，读取指定 Codex 任务的现有状态。与硬件版独立运行，不刷写硬件、不占用 USB、不更改 Codex 钩子。

## 打开与操作

打开 `build/钟离茶伴.app`。钟离默认出现在桌面右下角，没有 Dock 图标，不抢输入焦点。

- 左键拖动：移动钟离，自动保存位置。
- 右键或 Control 点击：切换番茄钟 / Codex 陪伴模式；番茄钟模式中可开始25分钟专注、暂停/继续、结束本轮。两种模式都可静音、隐藏和退出。
- 顶部菜单栏的“茶”：同样的菜单，隐藏后可从这里恢复。
- 番茄钟模式开始后，脚边出现小倒计时；Codex 模式只显示角色。
- 专注完成三声提示，等待手动开始休息；短休5分钟，累计每四轮长休15分钟。
- 开始短休播放已有语音，休息结束三声提示；静音时都不播放。音效顺序播放，避免互相截断。
- 退出后暂停恢复计时，不补播旧提醒；运行中约每30秒保存。电脑睡眠时间计入正在运行的时段，唤醒后若到点只完成当前一段，不连续补跑后续阶段。

## 动作

- 番茄钟模式：计时中阅读，暂停时小情绪，完成后举杯，等待时瞌睡。
- Codex 模式：工作时阅读，需要处理或错误时小情绪，本轮回复完成后短暂举杯，等待时瞌睡。
- 两种模式的动作互不覆盖。

Codex 状态不会产生声音，也不显示在桌面上，右键菜单可查看当前来源状态。完成仅表示该轮回复结束，不保证代码正确。

使用 --session 指定关注的一条任务，不自动追随当前窗口或汇总所有任务。可显式指定：

```sh
open 'build/钟离茶伴.app' --args --session YOUR_THREAD_UUID
```

如果应用已经运行，先从菜单退出再更换任务。状态来自已有的 `~/.confirmo/claude-status/sessions/` 文件，每两秒后台读取一次。十分钟没有来源更新时视为状态不可用，不把它当作完成。没有这个状态源时，桌宠和计时仍可离线使用。

## 性能与权限

使用 AppKit，不使用浏览器壳。四段视频在电脑上预处理为288×400透明PNG、8帧/秒；运行时仅保留最近4张图像缓存。隐藏时停止动画解码，计时和低频状态读取继续。不需要辅助功能、录屏或麦克风权限，不接管任何审批。

本地偏好（计时、模式、静音、位置、选定任务）保存在应用的 UserDefaults 中。没有开机自启、联网同步、勋章或任务详情面板。

## 开发

原始素材由用户提供，来自 Downloads 中的四段 MP4。不得在未确认素材权利的情况下当作可商业分发的美术包发布。

```sh
python3 tools/prepare_assets.py
./tools/build.sh
```

素材处理需 ffmpeg 和 Pillow；构建需 Xcode Command Line Tools。构建脚本先运行计时与模式状态测试，再编译并进行本机 ad-hoc 签名。构建不会打包本机任务编号。

图像裁剪细节、实际声音舒适度、多显示器拔插及长时间使用仍需人工体验。应用为本地试用版本，尚未进行公证或公开发布。

## 两个独立模式

右键钟离，或点击菜单栏“茶”，选择：

- **番茄钟模式**：显示脚边计时；动作只看专注、暂停、完成状态，不被 Codex 覆盖。
- **Codex 陪伴模式**：桌面只显示角色，动作只看选定的 Codex 任务，不被番茄计时覆盖。右键可查看来源状态和任务编号末8位。

首次使用默认 Codex 模式，之后记住选择。切换不会结束或暂停已开始的番茄钟；它继续后台计时，到点依然发声（除非静音），但不会抢走 Codex 动作。切回番茄钟模式可查看进度或开始下一段。

Codex 开工时阅读，需要处理时小情绪，从工作状态转为完成时举杯几秒，随后瞌睡。启动时读取到历史完成状态不补播庆祝。状态不可用不会被冒充成完成；具体原因和任务信息仅在右键菜单查看。

当前仍是一个指定任务的监控，不自动追踪鼠标焦点或所有任务。更换任务可使用上面的启动参数。现有状态来源能否识别所有审批/错误仍有限制。

## 仓库版素材

公开仓库不包含钟离角色和用户音频。直接构建会生成简单占位图与提示音，可运行基础功能。私人皮肤放入 `Assets/Animations/{read,doze,happy,piqued}/0000.png` 等连续帧，配套 `manifest.json` 每个动作声明 frames、fps、width、height。可选休息语音放入 `Assets/break-voice.mp3`。Assets 全部忽略，不进入 Git。构建不打包个人任务编号，使用 --session 指定。
