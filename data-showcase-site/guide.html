Phase 1 Graduation Template

data-showcase-site

把“已经拿到的数据”打包成可读、可交付、可发布的静态站点。它不是重分析工具，而是一个面向人看的报告站点生成器。

Input: CSV / JSON / MD / HTML Output: Static report site Validation: build --use-examples Optional: Publish

What Changed

这轮稳定化的重点，是把“可用脚本”变成“可审核的稳定 skill”。

01

统一定位

定义成“静态报告站点生成器”，不是泛化的数据分析平台。

02

补内置示例

补齐 `examples/reports/demo.json` 和 `examples/assets/demo.svg`，让 `--use-examples` 真正可跑。

03

补视觉导览

给审核和交接的人一个一眼能看懂的 guide 页面。

How To Use

先跑例子，再接真实数据。这样审核最稳，也最容易排除环境问题。

最小验证命令

cd /Users/yangyuan/Desktop/Codex版小工具upup/MyStableSkills/data-showcase-site
python3 main.py build --use-examples

真实构建命令

cd /Users/yangyuan/Desktop/Codex版小工具upup/MyStableSkills/data-showcase-site
python3 main.py build --reports /absolute/path/to/reports --out out/site

Input / Output

审核只要看边界是否清楚，不需要先看所有实现细节。

Input

  • CSV / TSV
  • JSON 报告
  • Markdown / HTML 现成内容
  • 可选图片资源

Output

  • `out/site/index.html`
  • 每个报告对应 `r//index.html`
  • 可选发布到 branch 或独立 repo

Review Checklist

审核员最少看这 3 条就够。

文档

  • SKILL.md 是否准确描述“已有数据 -> 静态站点”
  • 输入/输出边界是否明确
  • 最小验证命令是否简洁可执行

执行

  • `python3 main.py build --use-examples` 是否能生成站点
  • 示例页面是否能打开
  • guide 页面是否把使用方式说明清楚
