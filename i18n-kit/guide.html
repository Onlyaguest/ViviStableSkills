i18n-kit

面向报告页和轻量静态项目的离线优先国际化工具。核心价值不是“翻译很多语言”，而是先把文案 token 化、把字典落盘、把切换器做成完全离线可用的交付物。

Phase 1 Goal
Unified Entry
把 `i18n-kit` 和 `i18n-translator` 这条能力族收敛成一个统一入口。

What Changed

这轮不是再造一个翻译器，而是把现有能力族收敛成一个稳定、可审、可演示的 skill 包。

01

统一入口

把离线 token 化、apply、embed-switch 和 AI 翻译脚本收在同一个 `i18n-kit` 目录。

02

示例可跑

补了 `examples/site/demo.html`，让审核时不需要再准备自己的项目。

03

审核友好

把最小验证锁定在无 API 的离线路径，避免被翻译 key 卡住。

Workflow

这是一个先抽取、再翻译、再应用、最后切换的四步流。

1. Extract

  • 扫描中文文案
  • 生成 `i18n/zh-CN.json`
  • 可选把源码替换成 token

2. Translate

  • 手工翻译 JSON
  • 或用 `translate.py` 调 AI 生成目标语言

3. Apply

  • 输出目标语言目录
  • 保留原项目不变

4. Embed Switch

  • 给单个 HTML 注入离线切换器
  • 适合报告页和交付页

Review Checklist

审核员只需要看这 3 条。

文档

  • SKILL.md 是否说清“离线优先 i18n”定位
  • 输入/输出边界是否明确
  • 是否强调先 `--dry-run` 再 `--write`

执行

  • `extract --dry-run` 是否能跑通
  • 示例 HTML 是否足够演示
  • `main.py` / `translate.py` 是否可编译
