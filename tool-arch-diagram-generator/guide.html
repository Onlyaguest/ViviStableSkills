How It Works

一个三步流程，专门压缩成可交接、可复用、可审核的最小闭环。

Step 01

准备 Markdown

把 Mermaid 放进标准 fenced code block。推荐直接用 ```mermaid，这样解析最稳。

Step 02

先做 Dry Run

先确认 block 被识别，避免直接生成后才发现 Mermaid 没抓到。

Step 03

生成离线 HTML

脚本会把本地 mermaid.min.js 带进去，输出可分享的本地页面。
