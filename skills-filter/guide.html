Phase 2 Fast Win

skills-filter

在你开始做一个新 skill 之前，先过这 5 个问题。它的目标不是产出文档，而是尽快拦住“通用 AI wrapper”这种低价值方向。

Input: skill idea Output: build / deepen / reject Validation: --example Best fit: skill triage
Question Count
5
全部是 yes/no，没有模糊打分。
Primary Goal
Kill Bad Ideas Fast
先拦掉泛化包装，再决定要不要投入工程时间。
Good Outcome
5/5
说明这个方向有差异化、有积累、有壁垒。
Bad Outcome
0-2/5
说明它大概率只是换皮，应该停手或重构命题。

5 Questions

这 5 个问题就是这个 skill 的核心。它不复杂，但要被稳定复用。

01

差异化

跟“直接丢给 AI”有什么明显区别？

02

垂直性

有行业偏向性或场景偏向性吗？

03

积累性

会越用越聪明吗？

04

难度

用户自己很难做到吗？

05

壁垒

有壁垒吗？

How To Use

先跑一个内置示例，确认这个筛选器的口径，再拿真实 skill 想法进来打分。

最小验证

cd /Users/yangyuan/Desktop/Codex版小工具upup/MyStableSkills/skills-filter
python3 main.py --example lawyer-email-assistant

真实评估

cd /Users/yangyuan/Desktop/Codex版小工具upup/MyStableSkills/skills-filter
python3 main.py --title "创业者精力风控系统" --answers y,y,y,y,y

Decision Bands

评分不是为了显得科学，而是为了快速决策。

值得做

  • 5/5：立即做
  • 3-4/5：可以做，但先补 moat

不值得做

  • 1-2/5：不要做
  • 0/5：绝对不要做
