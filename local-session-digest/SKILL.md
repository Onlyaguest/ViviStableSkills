# Local Session Digest

在当前运行的 agent 环境中发现并读取本地会话，把真实工作压缩成可回溯的日常记录。本 skill 自包含，不依赖其他 skill、私人目录、账号或服务。

## 功能概览

- 跨项目发现当前本地 agent 的会话，包括归档会话。
- 按真实 turn 的时间筛选，区分主动请求、派工和自动任务。
- 每会话一份总结，另生成按活动时间排序的 Activity Digest。
- 保留失败、中断、等待、无新增产物和未验收状态。
- 输出覆盖范围、缺口与去重 manifest。
- 只读源会话、只写本地文件；不读取 Cohub，不连接或写入 Roam。

## 快速开始

把本目录安装到当前 agent 的 skill 搜索目录，然后直接请求：

> 使用 local-session-digest，总结昨天这个本地 agent 的所有会话。

也可指定日期、时区和输出目录：

> 总结 2026-06-03 至 2026-06-05 的本地会话，时区 Asia/Shanghai，输出到 ./output/review。

这是由宿主 agent 执行的工作流，不是独立模型或后台服务。读取接口和操作方法见 [本地来源适配](references/local-sources.md)，完整输出格式见 [格式合同](references/output-format.md)。

## 命令参考

| 输入项 | 默认与含义 |
|---|---|
| 时间窗 | 未指定时为用户当地昨天 00:00 至今天 00:00，左闭右开 |
| 时区 | 优先用户/客户端时区，其次系统时区；写进输出，不固定为作者所在地 |
| 会话范围 | 当前 agent 当前本地配置下、跨所有项目的会话；不是只取当前聊天，也不是只取当前工作目录 |
| 全部历史 | 用户明确说全部历史时取消日期筛选，仍限定当前本地 agent |
| 输出目录 | 当前工作目录下 output/session-digest/<日期或窗口>/ |
| 增量 | 相同窗口及来源复用 manifest，只更新有新证据的会话 |
| 预览 | 先列候选与覆盖缺口，不写总结文件 |

“所有会话”指时间窗内实际活跃的全部会话，不要求此刻仍在运行。当前 agent 是 Codex 时只查当前本地 Codex；其他宿主只查该宿主能合法访问的本地历史，不顺带扫其他产品、远程主机、云端协作空间或其他人的配置。

## 工作流

### 1. 定义来源和覆盖

记录 agent 名称、本地配置/host 范围、窗口、时区、当前时间、输出目录。
先检查输出目录的 manifest，避免重复生成。不得把用户刚才的新要求算进昨天。

优先使用当前宿主提供的本地会话列表和历史读取接口。读取到分页末尾或可靠越过窗口边界；列表更新时间只是候选条件。
列表未包含归档、旧项目或全部历史时，以本地会话目录/只读索引补候选。
每个候选最终必须读到真实 turn；不能把侧栏预览、标题或已有一句摘要冒充总结。

如果无法证明“全部”覆盖，明确报告 partial、缺哪一段及原因。缺权限或来源缺失不是零活动，也不自动登录其他服务。

### 2. 筛选真实活动

- 按 turn 开始时间归入日期；会话创建时间只作元数据，不冒充当日活动时间。
- 截止时间之后的最终回答不倒填：截止时仍在执行就记进行中。
- 明确排除访问、置顶、标题变化、ambient UI、纯系统通知、继承/合并的旧 turns。
- 带系统包装但含真实用户请求的消息，提取请求后再判定，不能因为含标签就整条丢掉。
- 子任务按来源链归属；父会话的“已派出”与子任务的“已交付”各自记录，不重复声称两次完成。
- 自动任务及自动派生在每项中标明来源；用户要求单列时分成主动与自动两组，各组按时间排序。
- 当前本地环境含共享用户数据时，只纳入已确认属于用户的轮次；身份不明记覆盖缺口，不凭名字猜。
- 同一 turn 的事件日志、消息副本、fork 继承只计算一次。优先稳定 turn ID 加来源 session ID 去重。

### 3. 逐会话总结

按格式合同写一份 summary，覆盖窗口内相关请求、纠正、结果、失败和未完成项。
同一 session 的不同主题拆成 Events；同主题往返不机械按每条消息拆碎。
标题说明实际做了什么，保留原会话标题作为入口。

证据优先取最终回答中的结果和实际工具回执。只有计划没有产物时明确写无新增产物。
“工具已返回 completed”只证明轮次结束，不证明用户目标完成。
原会话自报测试通过须注明来源，不能说成本轮独立验收；不为写摘要重跑有副作用的测试。
可访问的本地产物核对存在性；远端链接只能引用原始输出，不为复盘访问其他服务。

过去的建议、推测、诊断式表述和报价不自动成为事实；保留原日期和待核验状态。
保留最新用户纠正，未接受的建议不变成承诺或待办。

### 4. 生成 Digest 和 manifest

用同一组已校对的事实生成独立摘要和 Digest，确保内容一致。
按活动段开始时间升序；超过 30 分钟且主题改变时可以拆段。
使用真实会话链接；宿主没有深链时引用真实本地记录，不伪造 URL。
窗口无活动时交付零活动报告与覆盖依据，不生成虚构事件。

manifest 保存来源、窗口、候选、纳入/排除原因、turn IDs、读取覆盖、摘要路径、产物路径及证据截至时间。
不在 manifest 保存原始聊天全文、密钥、工具参数或环境变量。

### 5. 交付检查

- 每个纳入 session 都有独立摘要；统计与去重后的 turn 数一致。
- 每项有时间、状态、证据、判断、下一检查和 source。
- 时间属于指定窗口，排序正确，跨日结果未倒填。
- 链接/路径来自真实来源，输出不含凭据和不必要的私人细节。
- 未覆盖部分显式列出；不得将部分读取说成全量完成。

默认最终只给会话数、活动段数、覆盖缺口（若有）和 Digest 文件链接。

## 配置说明

不需要 API key、网络或付费服务。只依赖宿主已有的本地历史读取能力和文件写入能力。
读取本地 Codex 目录时使用环境变量 CODEX_HOME，未设置才使用当前用户的 .codex 目录；不改用户配置，不将某人的路径固化进 skill。
输出目录已有相同批次时优先复用；证据变化时更新对应摘要并保留更新时间。要另存快照可追加时间后缀，不覆盖无关文件。

## 隐私与公开边界

摘要默认是用户的私人本地产物。源会话可能含登录凭据、商业数据、家庭沟通或私人链接；不复制密钥、认证头、带 token 的 URL、登录态或工具调用原文。必要时将敏感事件概括为目的、结果与待处理状态。
不把“脱敏过”当成公开授权。发布 skill 时只包含通用说明、合成示例和通用代码，不打包真实会话、输出目录、manifest、个人路径、身份 ID、公司域名或截图。
本 skill 不包含上传、发消息、写外部笔记、定时任务或修改源会话的步骤。

## 常见问题

**没有桌面会话工具怎么办？** 按适配说明读取当前宿主本地记录；无可靠记录时报告限制。

**能在其他 agent 上用吗？** 格式和工作流可复用；使用该宿主的真实本地接口，不臆造 Codex 兼容性。

**只有一页最近会话？** 补分页、归档或本地索引；仍不足则只能交 partial。

**会把我的历史上传吗？** 不会。所有产物只写本地，公开仓库只放 skill 本身。
