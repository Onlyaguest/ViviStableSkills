Phase 2 Skill Production Line

spec-workflow

把隐藏在 workspace 里的 `.spec-workflow` 变成公开、可初始化、可复用的稳定 skill。它的目标是让项目从产品意图到 requirements / design / tasks 有一个固定落点。

Input: project root Output: .spec-workflow scaffold Commands: init + new-spec Best fit: spec-first work
Templates
6
requirements / design / tasks / product / tech / structure
Directories
6
approvals / archive / specs / steering / templates / user-templates
Key Win
Visible
不再手抄隐藏目录，直接用稳定命令初始化。
Override
Supported
后续可以用 `user-templates/` 覆盖默认模板。

What Changed

这次稳定化的重点，不是复制 `.spec-workflow`，而是把它包装成对项目更友好的脚手架。

01

打包模板

把 6 类默认模板收进 skill 自带的 bundle。

02

公开入口

新增 `check`、`init`、`new-spec` 三个稳定命令。

03

保留 override

初始化时自动带上 `user-templates/README.md`，后面可按项目覆盖模板。

How To Use

先初始化，再建 feature spec。不要直接跳到写 tasks。

初始化项目

cd /Users/yangyuan/Desktop/Codex版小工具upup/MyStableSkills/spec-workflow
python3 main.py init --root /tmp/spec-demo --project-name "Spec Demo" --author Developer_Lead

创建功能规格

cd /Users/yangyuan/Desktop/Codex版小工具upup/MyStableSkills/spec-workflow
python3 main.py new-spec --root /tmp/spec-demo --name "dashboard sync" --author Developer_Lead
