What It Wraps

审核时要看清边界：它管理入口，不重新实现每个原子 task。

Typical Commands

  • clean / inbox-clean
  • merge / merge-ai
  • lint / fix / normalize
  • meeting-archive
  • daily-rollover
  • docs-sync

Constraint

  • 真实执行依赖现有 `MyNotesTools` 仓库
  • 不适合脱离 notes repo 单独运行所有子流程
  • 有改动风险的流程应先走 dry-run
  • `docs-sync` 如无 Atlas MOC，可加 --skip-moc

Review Checklist

审核员最少看这 3 条就够。

文档

  • 输入 / 输出 / 依赖边界是否清楚
  • 是否提供不改 vault 的验证命令

执行

  • python3 main.py list 是否正常
  • python3 main.py check 是否能给出 config / mapping 结果
  • guide 页面是否能让非作者一眼看懂
